# Raw Continuation Payloads

These payloads are copy-pasteable examples for the `remote_agent` tool contract.

Use them with a local demo peer:

```bash
openclaw a2a demo serve --port 41234
```

The first `send` response returns `summary.continuation`. Replace the placeholder continuation in later payloads with that exact subtree.

See [payloads.json](./payloads.json).
